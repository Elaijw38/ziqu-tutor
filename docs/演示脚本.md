## 二、逐段台词

### 0:00–0:20 开场

**你说**：
> 这是我们做的甲骨文助教，叫龟宝，给郑大汉字类通识课的学生用。
> 它只依据课程材料回答，**每个结论都能点开核对出处**；查不到就直说没查到。
> 下面我用三个动作演示：问一个字、看它会不会编、然后让它自己出题判分。

**操作**：停在问答页，不要动。

---

### 0:20–0:55 问字（核心）

**操作**：输入 —— `家为什么是屋顶下有猪`

**你说（等答案出来时讲）**：
> 它不是泛泛地讲“家是温暖的港湾”，而是拆构件：上面宀是屋顶，下面豕是猪。
> 注意下面这几张图——**这是甲骨字形本身**，逐笔画出来的，不是画的插图。
> 再往下点开「出处」，能看到这句话出自课程材料的哪一条。

**操作**：点开「出处 · N 条」给他看一眼，再收起。

**你要强调的一句**：
> 出处是它自己检索出来的，不是我提前写好的。

---

### 0:55–1:15 证明不编

**操作**：输入 —— `今天郑州天气怎么样`

**你说**：
> 它会明确拒绝。这不是它不会查天气，是我们要求它**只答课程范围内的问题**。
> 一个教学助教乱答，比不答危险得多。

---

### 1:15–1:40 错误前提被纠正（最亮）

**操作**：输入 —— `木由宀和豕组成，对吗`

**你说（答案出来时讲）**：
> 注意，这是个**错误前提**。“木”不是由宀和豕组成的。
> 如果只靠大模型，它很可能顺着你答“对”。我们在模型之前加了一道**代码级核对**：
> 先查知识库里这个字真实的构件，对不上就先纠正，**不让模型自由发挥**。
> 它现在告诉你：不是，这是“家”的构件。

**停顿 2 秒**——这是评委最容易记住的一刻。

---

### 1:40–2:25 学情 → 出题 → 判分 → 再出题（证明是智能体）

**操作**：输入 —— `给我出三道题`

**你说（出题后）**：
> 注意这里：**我没有点任何按钮**，是它自己判断“该出题”，自己去调了出题工具。
> 答案存在服务端，它拿不到，所以不会泄题。

**操作**：直接输入 —— `三题都选 A`（故意全选 A，制造错题）

**你说（判分后）**：
> 它自己判断这是作答，调了判分工具，写回了学习记录。
> 现在学情页的数据已经变了——**这不是聊天，是有副作用的**。

**操作**：输入 —— `针对笔画再出一组`

**你说（新题出来后）**：
> 它自己挑了我最弱的“笔画”这个知识点，再出一组。
> 现在这条链是：**看学情 → 出题 → 判分 → 按弱点再出题**，四步都是它自己串的。

---

### 2:25–2:50 辨形题（教学性）

**操作**：点底部「**考考我**」，输入 `我想练认字`

**你说**：
> 这是甲骨文助教该有的题型：**只给字形，不给现代字**，四选一。
> 选项里有形近字，学生得真的认结构，而不是猜。
> 点「看答案」才给答案和解释，在这之前出处是藏着的。

---

### 2:50–3:00 收尾

**你说**：
> 总结一句：**模型是第三方的，但课程资料、约束和评测是我们做的。**
> 45 条固定评测集，问不到就拒答，错误前提会被拦下，这些都可以复现。
> 谢谢。

| 时刻 | 一句话 |

| **自主出题** | “我没有点按钮，是它自己判断该出题。” |

## 四、被问到时的回答（提前背）

| 问题 | 怎么答 |
|---|---|
| 这就是套了个 API 吧？ | “模型是第三方的，我们没否认。我们做的是课程资料、检索约束、学情诊断和评测——**45 条评测集可以当场跑给你看**。” |
| 算智能体吗？ | “它自己决定调检索、看学情、出题还是判分，四步都是自己串的，判分还会改学习记录。**这是可演示的，不是概念**。” |
| 会不会编造？ | “三类防护：只能引用知识库、拒答句式固定、错误前提有代码级核对。今天这条演示就是现场抓的。” |
| 数据哪来的？ | “甲骨字形用公开数据集，CC BY 4.0，DOI 在页脚；课程材料来自本人另一件作品，可逐条核。” |
| 用了学校什么数据？ | “**没有**。不接教务、不用学生个人信息，课程名和班级都标了‘示例，可配置’。” |
| 能规模化吗？ | “现在是单机 SQLite，按访客隔离。要上班级需要加教师端和部署，这是下一步，不吹已经做完。” |
| 和 Dify 那些有什么区别？ | “Dify 做单线问答；我们有学情数据层和判分回写，这是它做不了的。我们也用 Dify 做过对照。” |
| 效果怎么证明？ | “45 条评测集，六类问题，跑一次 3 分钟。**但我们不宣称证明了学习效果**，那需要真实班级前后测。” |

## 五、应急方案

| 状况 | 怎么办 |
|---|---|
| 模型超时 / 转圈超过 10 秒 | 说“网络有点慢，我先看这一步的结果”，切到**提前跑好的标签页**继续 |
| 完全断网 | 说“模型依赖网络，但知识库和诊断在本地”，切「学情诊断」「随堂练习」两页演示——**这两页不需要网络** |
| 答案不理想 | 不要辩解，说“这条答得不够好，我换一个角度问”，重问一次 |
| 评委追问细节 | 打开报告第七章「差距与风险」给他看：“这些我们都写下来了。” |
| 时间被压缩到 1 分钟 | 只演两个：**错误前提纠正** + **自主出题**，其余一句话带过 |
